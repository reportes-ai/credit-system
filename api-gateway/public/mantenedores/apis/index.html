Qué afecta este mantenedor
  • API Key por empresa → habilita/corta el acceso externo a la API correspondiente (la llave sirve SOLO para la API donde se creó). Desactivar corta el acceso al instante.
  • Regenerar llave → invalida la anterior (reenviar la nueva a la empresa).
  • Catálogo de APIs (tabla apis_catalogo) → cada fila es una card aquí. API Simulador Rápido usa el motor único del Simulador Rápido: cambios en Tasas, Parámetros de Crédito y Factores de Seguros se reflejan al instante en la API.
