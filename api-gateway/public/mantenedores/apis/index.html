Documentación de la API — Simulador Rápido
Endpoint
GET https://afbs.autofacilchile.cl/api/publica/v1/simulador-rapido?monto=MONTO
Autenticación

Header X-API-Key con la llave entregada por AutoFácil. Sin llave (o con llave desactivada) la API responde 401/403.

Parámetros
  • monto — saldo a financiar en pesos chilenos, entero sin puntos. Entre 1.000.000 y 300.000.000.
Ejemplo (curl)
curl -H "X-API-Key: afk_SU_LLAVE" \
  "https://afbs.autofacilchile.cl/api/publica/v1/simulador-rapido?monto=8000000"
Respuesta

  "success": true,

  • cuota — cuota mensual en CLP, con gastos operacionales y seguros incluidos.
  • cae — Carga Anual Equivalente (%), definición oficial CMF.
  • tasa — tasa mensual vigente (%) según tramo de 200 UF.
  • monto_fin — monto financiado total (saldo + gastos + seguros).
Límites y errores
  • Máximo 60 consultas por minuto; sobre eso responde 429.
  • Monto fuera de rango → 400 con el detalle en error.
  • Los valores son referenciales y usan las condiciones vigentes del día (UF, tasas, gastos y seguros de AutoFácil).
Qué afecta este mantenedor
  • API Key por empresa → habilita/corta el acceso externo a /api/publica/v1/simulador-rapido. Desactivar la llave corta el acceso al instante.
  • Regenerar llave → invalida la anterior (hay que reenviar la nueva a la empresa).
  • El cálculo sale del motor único del Simulador Rápido: cambios en Tasas, Parámetros de Crédito y Factores de Seguros se reflejan de inmediato en la API.
