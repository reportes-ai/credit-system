Qué afecta este mantenedor
  • Destinatarios de cada aviso → a quién le suena la campanita y le llega el push al celular. No cambia permisos: alguien puede recibir el aviso y no poder resolverlo, o poder resolverlo y no querer el aviso. Los permisos se administran en Usuarios y Perfiles.
  • Permiso base → cuando está activado, entran automáticamente todos los que tengan esa funcionalidad habilitada en la matriz de Perfiles. Es el comportamiento histórico: si lo apagas, mandan solo los perfiles y usuarios que marques acá.
  • Incluir Administradores → suma a todos los perfiles Administrador. Útil apagarlo para sacar cuentas de servicio o de prueba del reparto.
  • Excluir usuarios → saca a alguien puntual aunque su perfil lo incluya (p. ej. la cuenta una cuenta protegida o un usuario de prueba).
  • Activo / prioridad / sonido → si el aviso se emite, y cómo se comporta la campana (prioridad alta insiste con sonido hasta que se lee).
  • Cartel push en pantalla → además de la campanita, baja el cartel desde arriba en cualquier pantalla del sistema, con la duración en segundos que se elija. Se usa, por ejemplo, en las publicaciones nuevas de Facilbook.
  • Cartas → Aprobaciones · Créditos → Créditos · Fundantes → Fundantes Operaciones · Plan Liquidez → Hojas de Liquidación.
Todavía fuera de este mantenedor: los avisos de Comisiones y de Fichas de Dealer tienen su propia configuración, anterior a esta pantalla. Se van a consolidar acá; mientras tanto, se editan en su propio mantenedor.
