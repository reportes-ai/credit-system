Parámetros del Dashboard

Metas y umbrales que antes vivían en el código: acá los cambia el Administrador sin programador. El dashboard los aplica en la próxima carga.

Meta de prospección

Regla comercial: cuántos ingresos debe digitar cada ejecutivo por día hábil (lunes a sábado). Bajo la meta, el diagnóstico del funnel marca "⚠ Prospección".

Alertas rojas de colocación

Bajo estos montos, el Total Financiado se pinta rojo en las tablas del dashboard.

Semáforo de rentabilidad (%)

Colorea los porcentajes de margen (%_A, %_D, %_t, %_B) en Rentabilidades y P&L Operativo. Debe cumplirse verde ≥ amarillo ≥ naranjo; bajo el naranjo, rojo.

Qué afecta este mantenedor

  • Meta de prospección → KPI "Meta Ing./Ejecutivo", columna Meta, semáforo Ing./día, diagnóstico "⚠ Prospección" y gráfico de barras del Dashboard → Funnel/Prospección.
  • Alerta roja por ejecutivo → color del Total Fin. en Dashboard → Otorgados → Ejecutivos.
  • Alerta roja del mes anterior → color del Total Financiado en Dashboard → Resumen Mes Anterior.
  • Semáforo de rentabilidad → colores de los % de margen en Dashboard → Rentabilidades y P&L Operativo.
