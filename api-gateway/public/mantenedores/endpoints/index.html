Qué afecta este módulo:
  • Nada — es solo lectura del código fuente. No cambia rutas ni permisos.
  • Escritura SIN permiso → candidatas a blindar con requireFunc (algunas son legítimas: cambiar la propia clave, marcar visto un aviso). La lista es el pendiente vivo de la auditoría de seguridad.
  • Públicas → deben ser deliberadas: login, webhook de WhatsApp, verificación QR, portal cliente/dealer. Una pública que no calce en esa lista es un hallazgo.
  • Los permisos se administran en Usuarios → Perfiles y Permisos.
