Excepciones Comerciales
Parámetros del Simulador de Excepciones del Ejecutivo: estrellas mensuales, comodín dorado, códigos de aprobación y pisos de rentabilidad. El generador y validador de códigos leerán SIEMPRE estos valores.

Qué afecta este mantenedor
  • Piso de rentabilidad (75%) → el Simulador de Excepciones rechaza toda combinación (baja de tasa / baja de comisión dealer) cuya rentabilidad quede bajo este % de la alternativa más rentable, y propone la rebaja de comisión dealer (neta, sin IVA) que devuelve la operación al piso.
  • Rebaja máxima de tasa Unidad → % relativo sobre la tasa pizarra (pizarra 2,70% → mínimo 2,56%, redondeando hacia abajo); una baja mayor fuerza la operación a Autofin. La comparación de financieras usa el mismo motor de ¿Dónde Curso?.
  • Estrellas mes 1 y % mensual → presupuesto de excepciones de cada Ejecutivo Comercial que mostrará la pantalla de Cartas de Aprobación (estrellas sobre el generador). El redondeo es hacia abajo: es el aliciente para colocar al menos 3 al mes.
  • Vigencia del código (24 h) → un código no usado dentro del plazo vence y la estrella se devuelve dentro del mismo mes; las estrellas no usadas al cierre del mes expiran.
  • Comodín dorado → se gana 1 cada N otorgadas acumuladas; aprueba cualquier operación cuya rentabilidad AutoFácil supere en el % configurado a la más alta entre la comisión del dealer y la del ejecutivo.
  • Tolerancia de saldo y dígitos del código → validación del código en la Carta de Aprobación y en el Validador público (saldo precio + primeros dígitos del RUT + vigencia).
  • Plazos del simulador → columnas de cuota aproximada (12 / 24 / 36 / 48) que sirven de approach en la negociación con el cliente; las cuotas se calculan con el motor de Cotizaciones y las tasas vigentes de Tasas.
  • Umbral "Decides Tú" (solo lectura) → es el mismo pref_diff_pct de ¿Dónde Curso?; se edita en Parámetros (una sola fuente).
