Qué afecta este mantenedor
  • Documento obligatorio → traba el botón Enviar del ejecutivo hasta que esté subido, y cuenta en el "Faltan N" de Seguimiento Fundantes — Ejecutivo Comercial.
  • Documento opcional → se puede subir igual y queda a la vista, pero no impide enviar a validación. Aparece como "Subir (opc.)".
  • Solo si viene contratado → se exige únicamente cuando la operación trae ese producto vendido (GPS o limitación). Es el estado intermedio: ni siempre ni nunca.
  • Financiera → determina en qué operaciones aparece la columna. Una operación de otra financiera muestra "—" y no lo pide nunca.
  • Orden → el orden de las columnas en la grilla del ejecutivo y en Validación por Operaciones.
  • Agregar o quitar un documento → cambia también el ZIP que descarga Operaciones y el detalle del Historial de Fundantes.
