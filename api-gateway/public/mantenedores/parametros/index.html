Sobre $0 pero bajo este monto, la prima se considera un dato corrupto y el crédito vuelve a la cola de Digitación. El $0 explícito sigue siendo válido ("no se contrató").
Qué afecta este mantenedor
  • Gastos operacionales → se capitalizan en el monto financiado y entran al costo de cada operación en Dashboard → Rentabilidades y en las Cotizaciones.
  • Prima de seguro mínima válida → qué créditos entran a la cola de Digitación de Datos Faltantes y al cuadro de otorgados incompletos (mismo motor para los dos).
