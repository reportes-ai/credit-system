Qué afecta este proceso
  • Aprobación final (Administrador o permiso rh_ingresos_aprobar en Perfiles: Gerente de Operaciones) → crea el usuario en Usuarios con el perfil elegido como cargo y envía el correo con usuario y clave temporal
  • Supervisor → queda como jefatura en la ficha (Colaboradores), organigrama y aprobaciones de ausencias
  • Campos de la ficha (contrato, previsión, sueldo, pago, cargas, contacto) → se vuelcan a la ficha en Colaboradores, que alimenta Remuneraciones y Previred
  • Documentos (curriculum, carta oferta, contrato, título, cédula, informe comercial) → pasan a la Carpeta Digital del colaborador al aprobar
  • Cargo → lista viva de Perfiles: un perfil nuevo aparece solo
