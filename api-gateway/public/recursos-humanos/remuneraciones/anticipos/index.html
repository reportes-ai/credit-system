Qué afecta
  • Pendientes vienen de Adicionales (casilla "Pagado como anticipo") y Descuentos (tipos Anticipo y Préstamo). Generar el lote los marca como pagados por TEF.
  • Cuenta de origen → columna Cta_origen del archivo Santander (rh_config tef_cta_origen).
  • Datos bancarios y correo → salen de la ficha del colaborador; sin cuenta o banco sin código no se puede generar.
  • ODP → Órdenes de Pago: se crea "DE ACUERDO A NÓMINA ADJUNTA" con el Excel adjunto cuando hay más de una persona, o se ata a la ODP existente que indiques.
  • Correos → plantillas anticipo_fiestas_patrias, anticipo_navidad, anticipo_sueldo, anticipo_prestamo, anticipo_otro en Correos del Sistema.
