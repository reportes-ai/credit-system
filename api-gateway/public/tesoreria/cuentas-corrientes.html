Qué afecta este módulo
  • Cargar cartola → anexa movimientos a la misma fuente que usa la Conciliación Bancaria: lo cargado aquí queda disponible allá para conciliar (y viceversa).
  • Cuentas → son las de Conexiones Bancarias; las cuentas nuevas se crean allá o en Conciliación (cuenta manual).
  • Cargas → quedan registradas en Auditoría (acción IMPORTAR).
